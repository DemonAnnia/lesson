# Логика в 8 классе: тренажёр и два лонгрида

Учебные материалы к теме «Элементы математической логики» (информатика, 8 класс). Всё работает в браузере, без установки и без внешних библиотек.

| Страница | Что это |
|---|---|
| `trainer/` | Тренажёр «Пять логических операций»: справочник (инверсия, конъюнкция, дизъюнкция, импликация, эквиваленция) с переключателями и лампой, режимы «значение», «формула», «таблица», три уровня, итоги по операциям |
| `longread-holmes/` | Лонгрид 1 «Дело о пропавшем пироге»: законы формальной логики (тождества, непротиворечия, исключённого третьего, двойного отрицания, достаточного основания) |
| `longread-alice/` | Лонгрид 2 «Чаепитие у Шляпника»: законы алгебры логики (де Моргана, дистрибутивность, поглощение, импликация через «или») |

## Как опубликовать на GitHub Pages
1. Создайте репозиторий на github.com (например, `logika-8`), загрузите в него все файлы из этой папки (Add file → Upload files, перетащите папки целиком).
2. Откройте Settings → Pages → Source: Deploy from a branch → ветка `main`, папка `/ (root)` → Save.
3. Через 1–2 минуты страницы откроются по адресу `https://<ваш-логин>.github.io/logika-8/`. Эту ссылку (или QR-код на неё) можно давать ученикам.

## Источники
- Содержание пяти операций, обозначения и часть примеров высказываний — по п. 9.2 пособия Н. Н. Самылкиной «Методика обучения информатике», часть 1 (с. 171–175). Крупные фрагменты пособия не перепечатываются.
- Герои лонгридов — из произведений, вошедших в общественное достояние (А. Конан Дойл, Л. Кэрролл).
- Иллюстрации созданы нейросетью по промтам автора. Перед публикацией проверьте условия использования вашего генератора изображений.

## Проверка
Законы и таблицы истинности проверены независимым пересчётом; тренажёр прогнан автоматически (генерация сотен вопросов каждого типа, полное прохождение кликами, отсутствие ошибок JavaScript).

## Технически
Каждая страница — один файл `index.html` (HTML + CSS + JavaScript, рисунки встроены). Результаты тренажёра сохраняются в `localStorage` браузера на устройстве ученика, на сервер ничего не отправляется. Поддерживается светлая и тёмная тема.
