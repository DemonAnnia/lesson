# Информатика: логика и моделирование

Учебные материалы к урокам информатики. Всё работает в браузере, без установки и без внешних библиотек.

| Страница | Класс | Что это |
|---|---|---|
| `trainer/` | 8 | Тренажёр «Пять логических операций»: справочник (инверсия, конъюнкция, дизъюнкция, импликация, эквиваленция) с переключателями и лампой, режимы «значение», «формула», «таблица», три уровня |
| `longread-holmes/` | 8 | Лонгрид «Дело о пропавшем пироге»: законы формальной логики (тождества, непротиворечия, исключённого третьего, двойного отрицания, достаточного основания) |
| `longread-alice/` | 8 | Лонгрид «Чаепитие у Шляпника»: законы алгебры логики (де Моргана, дистрибутивность, поглощение, импликация через «или») |
| `neuron/` | 9 | «Нейрон как модель»: модель нейрона «брать ли зонт», подбор весов и порога для операций «И», «ИЛИ», «НЕ», сеть из трёх нейронов для «исключающего ИЛИ», вопросы для самопроверки |
| `graphs/` | 9 | «Граф-мастерская»: весовая матрица → граф, степени вершин, кратчайший путь (список всех путей и шаги расчёта), число путей в графе без циклов, генератор задач с проверкой |

## Как опубликовать на GitHub Pages
1. Загрузите все файлы и папки из этого комплекта в репозиторий (Add file → Upload files). Если в репозитории уже лежат `trainer/` и лонгриды, достаточно добавить папки `neuron/` и `graphs/` и заменить `index.html` и `README.md`.
2. Settings → Pages → Source: Deploy from a branch → ветка `main`, нужная папка → Save.
3. Через 1–2 минуты страницы откроются по адресу вида `https://<логин>.github.io/<репозиторий>/`.

## Источники
- Содержание пяти логических операций, обозначения и часть примеров — по пособию Н. Н. Самылкиной «Методика обучения информатике», часть 1, п. 9.2; понятия моделирования и пример модели нейрона — по п. 9.3 того же пособия.
- Понятия темы «Графы» (граф, вершина, ребро, матрица смежности, весовая матрица, оптимальный путь, перебор вариантов) — по учебнику К. Ю. Полякова и Е. А. Еремина для 9 класса (БИНОМ. Лаборатория знаний, 2017, § 17).
- Герои лонгридов — из произведений в общественном достоянии (А. Конан Дойл, Л. Кэрролл). Иллюстрации созданы нейросетью по промтам автора: перед публикацией проверьте условия использования вашего генератора изображений.

## Проверка
Законы и таблицы истинности проверены независимым пересчётом. «Нейрон как модель»: решения для «И», «ИЛИ», «НЕ» и перебор весов сверены с независимым расчётом. «Граф-мастерская»: кратчайшие пути, число путей, степени вершин и ответы сгенерированных задач сверены с независимой реализацией на сотнях случайных графов. Все страницы прогнаны автоматически без ошибок JavaScript.

## Технически
Каждая страница — один файл `index.html` (HTML + CSS + JavaScript). Результаты тренажёра логики сохраняются в `localStorage` браузера на устройстве ученика, на сервер ничего не отправляется. Поддерживаются светлая и тёмная тема.
